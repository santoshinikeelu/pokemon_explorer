# Pokémon Explorer

Pokémon Explorer is a Next.js-based project that allows users to browse and explore Pokémon using the PokéAPI.

## 🚀 Features
- View Pokémon details dynamically
- Responsive design
- Dark mode support

## 🛠️ Installation

### 1️⃣ Clone the Repository
```sh
git clone https://github.com/santoshinikeelu/pokemon_explorer.git
cd pokemon_explorer
```

### 2️⃣ Install Dependencies
```sh
npm install  
```



### 4️⃣ Run the Development Server
```sh
npm run dev 
```
Then open [http://localhost:3000](http://localhost:3000) in your browser.
